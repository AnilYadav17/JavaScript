# JavaScript Learning & Reference Guide

Welcome to the **JavaScript** repository. This repository contains structured study notes, deep-dive theoretical concepts, modern ECMAScript standards, interactive web examples, and quick-lookup cheatsheets.

---

## 📚 Repository Structure

| File | Description |
| :--- | :--- |
| [`THEORY.md`](./THEORY.md) | In-depth theory covering JS fundamentals, history, V8 engine, JIT compilation, asynchronous model, event loop, OOP, and functional programming. |
| [`CHEATSHEET.md`](./CHEATSHEET.md) | Quick-reference syntax cheatsheet for ES6+, array methods, promises, and DOM manipulation. |
| [`1.html`](./1.html) | Interactive web application demonstrating DOM events, functional transformations, and async API calls. |

---

## 🚀 Key Topics Covered

- **JavaScript Fundamentals**: High-level abstractions, dynamic typing, syntax, and execution.
- **Engine & Compilation**: How modern engines (V8, SpiderMonkey, JavaScriptCore) utilize interpretation and Just-In-Time (JIT) compilation.
- **Object-Oriented & Functional**: Prototype-based inheritance, closures, higher-order functions (`map`, `filter`, `reduce`).
- **Asynchronous JavaScript**: Event Loop, Call Stack, Web APIs, Callback Queue, Promises, and `async`/`await`.
- **Standards & Specifications**: History of ECMAScript (from ES1 to modern annual releases), ECMA International.
- **Server-Side JS**: Node.js runtime and full-stack JavaScript architectures.
- **Framework Ecosystem**: Overview of React, Vue, Angular, Next.js, Express, and Jest.

## 🛠️ Running the Interactive Demo

To run the interactive demonstration:

1. Open `1.html` in your web browser:
   ```bash
   google-chrome 1.html  # or firefox 1.html
   ```
2. Interact with the live UI buttons to test:
   * Event-driven programming and click counts.
   * Functional array squaring via `.map()`.
   * Asynchronous Promise-based simulated delay.
