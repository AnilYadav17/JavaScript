# JavaScript Learning & Reference Guide

Welcome to the **JavaScript** repository. This repository contains structured study notes, deep-dive theoretical concepts, modern ECMAScript standards, and practical web development code examples.

---

## 📚 Repository Contents

| File | Description |
| :--- | :--- |
| [`THEORY.md`](./THEORY.md) | In-depth theory covering JS fundamentals, history, V8 engine, JIT compilation, asynchronous model, event loop, OOP, and functional programming. |
| [`1.html`](./1.html) | Practical HTML & JavaScript integration with DOM event handling. |

---

## 🚀 Key Topics Covered

- **JavaScript Fundamentals**: High-level abstractions, dynamic typing, syntax, and execution.
- **Engine & Compilation**: How modern engines (V8, SpiderMonkey, JavaScriptCore) utilize interpretation and Just-In-Time (JIT) compilation.
- **Object-Oriented & Functional**: Prototype-based inheritance, closures, higher-order functions (`map`, `filter`, `reduce`).
- **Asynchronous JavaScript**: Event Loop, Call Stack, Web APIs, Callback Queue, Promises, and `async`/`await`.
- **Standards & Specifications**: History of ECMAScript (from ES1 to modern annual releases), ECMA International.
- **Server-Side JS**: Node.js runtime and full-stack JavaScript architectures.

## 🛠️ Usage

To run or inspect the HTML and JavaScript examples:

1. Open `1.html` directly in any modern web browser:
   ```bash
   google-chrome 1.html  # or firefox 1.html
   ```
2. Open the browser's Developer Tools (`F12` or `Ctrl + Shift + I`) and view the **Console** tab to see script logs and outputs.
